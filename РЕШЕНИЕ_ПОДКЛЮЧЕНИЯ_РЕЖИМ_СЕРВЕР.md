# Решение проблемы подключения в режиме "Сервер"

## Проблема

Модем настроен в режиме "Сервер", но соединение не устанавливается, и статус показывает "Офлайн".

## Как работает режим "Сервер"

В режиме "Сервер" модем сам ждет подключений на указанном порту. Ваш сервер должен **подключаться к модему** как клиент.

**Важно:** Для работы в режиме "Сервер" нужно знать **IP-адрес модема**.

## Причины проблемы

### 1. IP-адрес модема не указан

**Симптомы:**
- В логах: `⚠️ Не могу определить IP модема для подключения в режиме Сервер`
- Статус модема: "Офлайн"

**Решение:**
1. Откройте вкладку **"Настройки"** в веб-интерфейсе
2. Выберите модем из списка
3. Убедитесь, что в поле **"IP-адрес модема"** указан правильный IP
4. Если IP не указан:
   - **Вариант А:** Укажите IP вручную (можно узнать из программы ATM Control SE)
   - **Вариант Б:** Сначала настройте модем в режиме "Клиент" - система автоматически узнает его IP

### 2. Модем не запустил сервер

**Симптомы:**
- В логах: `❌ Ошибка подключения: ECONNREFUSED`
- В логах: `❌ Таймаут подключения`

**Причины:**
- Модем еще не перезагрузился после настройки
- Модем не принял SMS-команды
- Порт указан неправильно

**Решение:**
1. Убедитесь, что SMS-команды отправлены и модем их принял
2. Подождите 1-2 минуты после настройки (модем должен перезагрузиться)
3. Проверьте, что порт указан правильно (обычно 2002 или другой порт из настроек модема)
4. Перезагрузите модем вручную через программу ATM Control SE

### 3. Неверный IP-адрес модема

**Симптомы:**
- В логах: `❌ Ошибка подключения: ETIMEDOUT` или `ENOTFOUND`
- Статус модема: "Офлайн"

**Причины:**
- IP-адрес модема изменился (модемы могут получать новый IP при переподключении к интернету)
- IP-адрес указан неправильно

**Решение:**
1. Проверьте текущий IP модема в программе ATM Control SE
2. Обновите IP-адрес в настройках веб-интерфейса
3. Или настройте модем в режиме "Клиент" - система узнает его IP автоматически

### 4. Файрвол блокирует подключение

**Симптомы:**
- В логах: `❌ Таймаут подключения`
- Подключение не устанавливается

**Решение:**
1. Проверьте настройки файрвола на сервере
2. Убедитесь, что исходящие подключения к модему разрешены
3. Проверьте, что модем не блокирует входящие подключения (если у модема есть файрвол)

## Пошаговая инструкция по настройке

### Шаг 1: Узнайте IP модема

**Способ 1 (рекомендуется):**
1. Настройте модем в режиме "Клиент" хотя бы раз
2. Когда модем подключится, система автоматически узнает его IP
3. Затем переключите модем в режим "Сервер"

**Способ 2:**
1. Откройте программу ATM Control SE
2. Подключитесь к модему
3. Посмотрите IP-адрес модема в информации об устройстве
4. Запишите этот IP

### Шаг 2: Настройте режим "Сервер"

1. Откройте веб-интерфейс
2. Перейдите на вкладку **"Настройки"**
3. Выберите модем из списка
4. Выберите режим **"Сервер"**
5. Укажите **порт** (обычно 2002)
6. **ВАЖНО:** Укажите **IP-адрес модема** в поле "IP-адрес модема"
7. Нажмите "Применить настройки"

### Шаг 3: Отправьте SMS-команды

Если SMS-шлюз не настроен, команды будут показаны в интерфейсе. Отправьте их на модем вручную через SMS.

**Команды для режима "Сервер":**
1. `5492 0AT$SRV_RCCNT=1` - включает режим сервер (не применяет)
2. `5492 1AT$SRV_PORT=2002` - устанавливает порт (ПРИМЕНЯЕТ и перезагружает)

**Важно:** Отправляйте команды **по порядку** с задержкой 5-10 секунд между ними!

### Шаг 4: Дождитесь перезагрузки модема

После отправки второй команды модем перезагрузится (обычно 30-60 секунд).

### Шаг 5: Проверьте подключение

1. Подождите 1-2 минуты после перезагрузки модема
2. Обновите страницу в веб-интерфейсе
3. Статус модема должен измениться на "Онлайн"

## Автоматическое переподключение

Система автоматически пытается переподключиться к модему в режиме "Сервер" каждые 30 секунд, если соединение потеряно.

## Проверка работы

### Проверка 1: Логи сервера

```bash
pm2 logs irz-modem-control --lines 50
```

Ищите сообщения:
- `✅ Подключился к модему [номер] в режиме Сервер` - подключение успешно
- `❌ Ошибка подключения` - есть проблема, смотрите детали ошибки

### Проверка 2: Статус в интерфейсе

В веб-интерфейсе на вкладке "Модемы" статус должен быть "Онлайн" (зеленый).

### Проверка 3: Отправка AT-команды

Попробуйте отправить AT-команду через вкладку "Мониторинг". Если команда выполняется успешно - подключение работает.

## Частые ошибки и решения

### Ошибка: "Не могу определить IP модема"

**Решение:** Укажите IP модема вручную в настройках или сначала настройте модем в режиме "Клиент".

### Ошибка: "ECONNREFUSED" (соединение отклонено)

**Решение:** 
- Модем не запустил сервер - перезагрузите модем
- Порт указан неправильно - проверьте настройки модема
- Модем не принял SMS-команды - отправьте команды еще раз

### Ошибка: "ETIMEDOUT" (таймаут)

**Решение:**
- IP-адрес модема неверный - проверьте и обновите IP
- Модем не подключен к интернету - проверьте статус модема
- Файрвол блокирует подключение - проверьте настройки файрвола

### Ошибка: "ENOTFOUND" (хост не найден)

**Решение:**
- IP-адрес указан неправильно - проверьте формат IP (например, 192.168.1.100)
- Модем недоступен по сети - проверьте, что модем включен и подключен к интернету

## Рекомендации

1. **Используйте режим "Клиент"** если не знаете IP модема - модем сам подключится к серверу
2. **Режим "Сервер"** удобен для мониторинга и отправки AT-команд напрямую
3. **Сохраняйте IP модема** - он может измениться при переподключении к интернету
4. **Проверяйте логи** при проблемах - там есть подробная информация об ошибках

## Дополнительная помощь

Если проблема не решена:
1. Проверьте логи сервера: `pm2 logs irz-modem-control`
2. Проверьте настройки модема в программе ATM Control SE
3. Убедитесь, что модем подключен к интернету и имеет стабильный IP-адрес
