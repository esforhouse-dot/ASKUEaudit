# 🚀 Запуск сервера

## 🔴 Проблема: ERR_CONNECTION_REFUSED

Ошибка означает, что сервер не запущен или не слушает на порту 3004.

---

## ✅ Решение: Запустить сервер

### Способ 1: Через командную строку (рекомендуется)

1. Откройте **командную строку** (cmd) или **PowerShell**
2. Перейдите в папку проекта:
   ```cmd
   cd C:\Users\ДИР\Desktop\ASK
   ```
3. Запустите сервер:
   ```cmd
   node server.js
   ```

**Или используйте npm:**
```cmd
npm start
```

### Способ 2: Через PowerShell

1. Откройте **PowerShell**
2. Перейдите в папку проекта:
   ```powershell
   cd "C:\Users\ДИР\Desktop\ASK"
   ```
3. Запустите сервер:
   ```powershell
   node server.js
   ```

## ⚠️ Если порт занят

Если видите ошибку:
```
❌ ОШИБКА: Порт 3004 уже занят!
```

**Решение:**
1. Найдите процесс, который использует порт:
   ```cmd
   netstat -ano | findstr :3004
   ```
2. Завершите процесс (замените PID на номер процесса):
   ```cmd
   taskkill /PID <номер_процесса> /F
   ```
3. Запустите сервер снова

## 🔄 Автоматический запуск при загрузке системы

### Через планировщик задач Windows:

1. Откройте **Планировщик задач** (Task Scheduler)
2. Создайте новую задачу:
   - **Триггер:** При входе в систему
   - **Действие:** Запустить программу
   - **Программа:** `node`
   - **Аргументы:** `C:\Users\ДИР\Desktop\ASK\server.js`
   - **Рабочая папка:** `C:\Users\ДИР\Desktop\ASK`

### Через pm2 (рекомендуется для продакшена):

1. Установите pm2:
   ```cmd
   npm install -g pm2
   ```
2. Запустите сервер:
   ```cmd
   pm2 start server.js --name "irz-modem-server"
   ```
3. Сохраните конфигурацию:
   ```cmd
   pm2 save
   pm2 startup
   ```

## 🐛 Решение проблем

### Проблема: "node не является внутренней или внешней командой"

**Решение:**
1. Установите Node.js: https://nodejs.org/
2. Перезапустите командную строку
3. Проверьте установку:
   ```cmd
   node --version
   ```

### Проблема: "Cannot find module"

**Решение:**
1. Установите зависимости:
   ```cmd
   npm install
   ```
2. Запустите сервер снова

### Проблема: Сервер запускается, но не отвечает

**Решение:**
1. Проверьте файрвол - порт 3004 должен быть открыт
2. Проверьте, что сервер слушает на правильном IP:
   - В коде должно быть: `app.listen(PORT, '0.0.0.0', ...)`
3. Проверьте логи сервера на наличие ошибок
