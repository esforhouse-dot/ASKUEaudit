## Осознанно не делаем сейчас

Фичи больших сетевых/сбытовых АСКУЭ, не релевантные масштабу этого проекта:
- интеграция с 1С/ERP/биллингом;
- карта/план объекта;
- приём показаний вручную (у проекта и так полная телеметрия, ручной ввод не нужен).

## Публичного API тарифов сбытовых компаний не существует

Проверено 30.08.2026 (веб-поиск): ни у ТНС Энерго, ни у других сбытовых компаний нет публичного
API тарифов — только HTML/PDF-таблицы по каждому региону отдельно, единого реестра тоже нет.
Поэтому в п.1 тариф вводится вручную, а не подтягивается автоматически по городу.
