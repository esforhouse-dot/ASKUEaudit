# Быстрый старт - Запуск сервера

## Проблема: Сервер останавливается при закрытии терминала

Если вы запускаете `npm start` и закрываете терминал, сервер останавливается. Для постоянной работы используйте PM2.

## Решение: Запуск через PM2

### 1. Установите PM2 (если еще не установлен)

```bash
sudo npm install -g pm2
```

### 2. Запустите сервер через PM2

**Простой способ (используйте готовый скрипт):**
```bash
chmod +x start-pm2.sh
./start-pm2.sh
```

**Или вручную:**
```bash
pm2 start server.js --name irz-modem-control
pm2 save
```

### 3. Проверьте статус

```bash
pm2 status
```

Вы должны увидеть процесс `irz-modem-control` в статусе "online".

### 4. Проверьте работу сервера

```bash
curl http://localhost:3003
```

Или откройте в браузере: **http://147.45.212.205:3003**

## Полезные команды PM2

```bash
pm2 status                    # Статус всех процессов
pm2 logs irz-modem-control    # Просмотр логов в реальном времени
pm2 logs irz-modem-control --lines 50  # Последние 50 строк логов
pm2 restart irz-modem-control # Перезапуск
pm2 stop irz-modem-control    # Остановка
pm2 delete irz-modem-control # Удаление из PM2
pm2 save                     # Сохранить конфигурацию
pm2 startup                  # Настроить автозапуск при загрузке системы
```

## Настройка автозапуска при перезагрузке сервера

```bash
pm2 startup
pm2 save
```

После этого сервер будет автоматически запускаться при перезагрузке VPS.

## Просмотр логов

```bash
# В реальном времени
pm2 logs irz-modem-control

# Последние 100 строк
pm2 logs irz-modem-control --lines 100

# Без потока (только последние строки)
pm2 logs irz-modem-control --nostream
```

## Остановка сервера

```bash
pm2 stop irz-modem-control
```

## Перезапуск после изменений в коде

```bash
pm2 restart irz-modem-control
```

## Проверка работы

После запуска через PM2 сервер будет работать постоянно, даже если вы закроете терминал.

Откройте в браузере: **http://147.45.212.205:3004**
