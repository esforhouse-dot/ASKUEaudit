# Как посмотреть команды для отправки на модем

## Способ 1: Прямо в интерфейсе (самый простой) ✨

После того, как вы примените настройки:

1. **Если SMS-шлюз не настроен** - команды автоматически появятся на странице "Настройки"
2. Вы увидите блок с заголовком **"📱 Последние команды для отправки"**
3. Рядом с каждой командой будет кнопка **"📋 Копировать"**
4. Скопируйте команду и отправьте её на номер модема через SMS с телефона

**Это самый удобный способ!** Команды показываются сразу после применения настроек.

---

## Способ 2: Через консоль сервера (для продвинутых)

Если вы хотите посмотреть все логи сервера, есть несколько способов:

### Вариант А: Через PM2 (если сервер запущен через PM2)

**Подключитесь к серверу по SSH** и выполните команды:

```bash
# Посмотреть логи в реальном времени (как они появляются)
pm2 logs irz-modem-control

# Посмотреть последние 50 строк логов
pm2 logs irz-modem-control --lines 50

# Посмотреть последние 100 строк и выйти
pm2 logs irz-modem-control --lines 100 --nostream
```

**Что вы увидите:**
- Все сообщения сервера
- Команды для отправки на модем (они будут выделены эмодзи 📱)
- Ошибки, если они есть

### Вариант Б: Через файлы логов

Логи также сохраняются в файлы:

```bash
# Посмотреть последние строки из логов
tail -n 50 logs/out.log

# Или посмотреть файл целиком
cat logs/out.log
```

Файлы находятся в папке `logs/`:
- `logs/out.log` - обычные сообщения
- `logs/err.log` - ошибки

### Вариант В: Если сервер запущен напрямую (не через PM2)

Если вы запустили сервер командой `node server.js` или `npm start`:

- Команды будут видны прямо в том терминале, где запущен сервер
- Просто посмотрите в окно терминала

---

## Как отправить команды на модем

После того, как вы получили команды (из интерфейса или логов):

1. **Скопируйте команду** (например: `5492 1AT$CLNT_IPP1=147.45.212.205,2001`)
2. **Откройте SMS на телефоне**
3. **Создайте новое сообщение** на номер модема (например: `89693808916`)
4. **Вставьте команду** в текст сообщения
5. **Отправьте SMS**

Модем получит команду, обработает её и применит настройки.

---

## Примеры команд

После настройки режима "Клиент" вы получите команды вида:

```
5492 0AT$CLNT_SET1=1,0,0,1
5492 1AT$CLNT_IPP1=147.45.212.205,2001
```

Где:
- `5492` - пароль модема (по умолчанию)
- `0` или `1` - применить сразу (1) или сохранить (0)
- `AT$CLNT_SET1` - настройка соединения №1
- `AT$CLNT_IPP1` - IP и порт для соединения №1

**Важно:** Отправляйте команды по порядку, одну за другой, с небольшой задержкой (5-10 секунд).

---

## Рекомендация

**Используйте Способ 1 (интерфейс)** - это самый простой и удобный способ. Команды показываются сразу после применения настроек, их можно скопировать одним кликом.

Если нужны все логи сервера для диагностики - используйте Способ 2.
