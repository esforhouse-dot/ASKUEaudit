# PROJECT

## Product
АСКУЭ SaaS «Дом Инженерных Решений».

## Ценность
Простая коммерческая автоматизация учёта электроэнергии для средних объектов без сложности enterprise-АСКУЭ.

## Hardware
- iRZ ATM42.B / ATM.21B
- Mercury 230/234/236
- RS-485
- CT-based metering where required

## Existing capabilities
- modem/GSM/LTE monitoring
- meter readings and instantaneous values
- hourly consumption
- 10-minute snapshots
- tariffs and historical tariff changes
- rental/technical/commercial accounting
- XLSX/CSV
- scheduled reports
- incidents and notifications
- roles Master/User
- GPIO
- multiple meters on RS-485
- multitenancy
- responsive UI

## Planned
- power quality/GOST monitoring
- period comparisons
- Telegram/SMS/Push/PWA/mobile

## Explicitly not planned
- 1C/ERP/billing integration
- object maps/plans
- manual readings
