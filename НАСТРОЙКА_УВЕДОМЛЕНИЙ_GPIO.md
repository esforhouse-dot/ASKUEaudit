# Настройка уведомлений о изменении GPIO

## 📋 Что это дает?

Теперь система может отправлять Telegram уведомления о изменении состояния GPIO в двух случаях:

1. **Физическое изменение GPIO** - когда кто-то физически меняет состояние входа/выхода (например, нажал кнопку, сработал датчик)
2. **Команда из веб-интерфейса** - когда вы отправляете команду на изменение GPIO через веб-интерфейс

---

## ⚙️ Как это работает?

### Для физических изменений GPIO:

1. **Модем автоматически отправляет данные** через TCP-соединение при изменении GPIO
2. **Сервер получает данные** и парсит информацию о GPIO
3. **Отслеживаются изменения** - уведомление отправляется только при реальном изменении состояния
4. **Telegram уведомление** отправляется автоматически

### Для команд из веб-интерфейса:

1. Вы отправляете команду через веб-интерфейс
2. Команда отправляется на модем через TCP
3. Telegram уведомление отправляется сразу после отправки команды

---

## 🔧 Настройка модема для физических изменений GPIO

Чтобы получать уведомления о **физических изменениях** GPIO, нужно настроить модем:

### Шаг 1: Настроить GPIO как вход

Настройте нужный GPIO как вход (через программу ATM Control SE или SMS-командами):
- GPIO1, GPIO2, GPIO3 могут быть настроены как входы

### Шаг 2: Включить автоматическую отправку данных о GPIO

Отправьте SMS-команду на модем:

```
5492 0AT$GPIO_SEND1=1
5492 1AT$CLNT_SET1=1,0,0,1
```

**⚠️ ВАЖНО:** НЕ используйте `AT$ATM_RESET` - это команда для СБРОСА всех настроек к заводским!

**Пояснение:**
- `GPIO_SEND1=1` - включить автоматическую отправку данных о GPIO1 через клиентское соединение №1
- Для GPIO2 используйте `GPIO_SEND2=1`, для GPIO3 - `GPIO_SEND3=1`

**Важно:**
- Модем должен быть настроен в режиме "Клиент"
- Должна быть включена инкапсуляция (`CLNT_SET1=1,0,0,1`)
- Модем должен быть подключен к серверу через TCP

## 📱 Настройка Telegram уведомлений

### Шаг 1: Включить уведомления в веб-интерфейсе

1. Перейдите на вкладку **"Конфигурация"**
2. Найдите раздел **"Правила уведомлений"**
3. Выберите нужные уведомления:
   - **"☑ Физическое изменение GPIO"** - для уведомлений о физических изменениях (датчик/кнопка)
   - **"☑ Команды GPIO из веб-интерфейса"** - для уведомлений о командах, отправленных через веб-интерфейс
4. Нажмите **"Сохранить настройки Telegram"**

**Рекомендация:** Если вы хотите получать уведомления только о **реальных физических изменениях**, включите только первую галочку.

### Шаг 2: Проверить настройки

Убедитесь, что:
- ✅ Telegram Bot Token указан
- ✅ Chat ID получателей указан
- ✅ Правило "Изменение GPIO" включено

- ✅ Заголовок: "Физическое изменение GPIO"

**Отличительные признаки:**
- ✅ Заголовок: "GPIO установлен в..."
- ✅ Указан источник: "Команда из веб-интерфейса"
- ✅ Показывает метод отправки (TCP/SMS)

## 🔍 Как проверить, что все работает?

### Проверка 1: Физическое изменение GPIO

1. Настройте модем на автоматическую отправку данных (`GPIO_SEND1=1`)
2. Физически измените состояние GPIO (например, подключите/отключите вход)
3. Проверьте Telegram - должно прийти уведомление

### Проверка 2: Команда из веб-интерфейса

1. Перейдите на вкладку **"Входы/Выходы"**
2. Выберите модем
3. Нажмите кнопку для изменения состояния GPIO
4. Проверьте Telegram - должно прийти уведомление

### Проверка 3: Логи сервера

Проверьте логи сервера - там должны быть сообщения:
- `📱 Извлечено состояние GPIO1 из данных модема...`
- `📢 Отправлено Telegram уведомление об изменении GPIO1...`

---

## ⚠️ Важные замечания

1. **Для физических изменений:**
   - GPIO должен быть настроен как **вход**
   - Должна быть включена команда `GPIO_SEND<X>=1`
   - Модем должен быть подключен через TCP

2. **Формат данных:**
   - Система поддерживает различные форматы данных от модема
   - Если формат не распознается, проверьте логи сервера

3. **Дублирование уведомлений:**
   - Уведомления отправляются только при **реальном изменении** состояния
   - Если состояние не изменилось, уведомление не отправится

4. **Производительность:**
   - Система отслеживает изменения эффективно
   - Не будет лишних уведомлений при одинаковых значениях

---

## 🐛 Решение проблем

### Проблема: Уведомления не приходят при физическом изменении GPIO

**Решение:**
1. Проверьте, что модем настроен на отправку данных: `AT$GPIO_SEND1=1`
2. Проверьте, что модем подключен через TCP
3. Проверьте, что инкапсуляция включена
4. Проверьте логи сервера - должны быть сообщения о получении данных

### Проблема: Уведомления не приходят при команде из веб-интерфейса

**Решение:**
1. Проверьте, что правило "Изменение GPIO" включено в настройках Telegram
2. Проверьте, что Telegram Bot Token и Chat ID указаны правильно
3. Проверьте логи сервера на наличие ошибок

### Проблема: Приходят уведомления, но формат неправильный

**Решение:**
- Проверьте логи сервера - там будет видно, какой формат данных приходит от модема
- Если формат не распознается, можно добавить поддержку нового формата в код

## 📝 Примеры SMS-команд для настройки

### Включить автоматическую отправку данных о GPIO1:

```
5492 0AT$GPIO_SEND1=1
5492 1AT$CLNT_SET1=1,0,0,1
```

**⚠️ ВАЖНО:** НЕ используйте `AT$ATM_RESET` - это команда для СБРОСА всех настроек к заводским!

### Включить для нескольких GPIO:

```
5492 0AT$GPIO_SEND1=1;AT$GPIO_SEND2=1;AT$GPIO_SEND3=1
5492 1AT$CLNT_SET1=1,0,0,1
```

### Отключить автоматическую отправку:

```
5492 0AT$GPIO_SEND1=0
5492 1AT$CLNT_SET1=1,0,0,1
```
