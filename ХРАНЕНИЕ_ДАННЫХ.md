# Система хранения данных

## Текущая система

Сейчас используется **JSON файл** для хранения данных:
- `modems.json` - список модемов и их настройки
- `sms-config.json` - конфигурация SMS-шлюза

## Как это работает

### Сохранение данных

1. **Автоматическое сохранение** при каждом изменении:
   - Добавление модема
   - Изменение настроек модема
   - Изменение конфигурации SMS

2. **Резервные копии**:
   - Перед каждым сохранением создается копия `.backup`
   - При ошибке загрузки система пытается восстановить из резервной копии

3. **Проверка сохранения**:
   - Если сохранение не удалось, возвращается ошибка
   - Все ошибки логируются в консоль

### Загрузка данных

1. **При старте сервера**:
   - Автоматически загружаются все модемы из файла
   - Если файл не найден - создается новый

2. **Восстановление**:
   - При ошибке чтения файла система пытается загрузить из резервной копии
   - Если и это не удалось - создается новый пустой файл

## Где хранятся файлы

Файлы находятся в корне проекта:
```
ASK/
  ├── modems.json          # Данные модемов
  ├── modems.json.backup   # Резервная копия
  ├── sms-config.json      # Конфигурация SMS
  └── server.js
```

## Проверка работы

### Проверить, что файлы создаются:

```bash
# Посмотреть файлы
ls -la modems.json sms-config.json

# Посмотреть содержимое
cat modems.json
```

### Проверить логи сервера:

```bash
pm2 logs irz-modem-control --lines 50
```

Должны увидеть:
- `✅ Загружено модемов: X` - при старте
- `💾 Настройки модемов сохранены (X модемов)` - при сохранении

## Если данные не сохраняются

1. **Проверьте права доступа**:
   ```bash
   ls -la modems.json
   ```
   Файл должен быть доступен для записи

2. **Проверьте логи сервера**:
   ```bash
   pm2 logs irz-modem-control
   ```
   Ищите ошибки с текстом "Ошибка сохранения"

3. **Проверьте место на диске**:
   ```bash
   df -h
   ```

4. **Проверьте, что файл создается**:
   ```bash
   # После добавления модема проверьте
   cat modems.json
   ```
