# Инструкция: Проверка файрвола на Linux VPS

## Шаг 1: Подключитесь к серверу

Используйте SSH для подключения к вашему VPS:
```bash
ssh ваш_пользователь@147.45.212.205
```

## Шаг 2: Проверьте, какой файрвол установлен

Выполните команды по очереди:

### Проверка UFW (самый простой файрвол)
```bash
sudo ufw status
```

Если видите список правил или "Status: active" - используется UFW.

### Проверка firewalld
```bash
sudo systemctl status firewalld
```

Если видите "active (running)" - используется firewalld.

### Проверка iptables (базовый файрвол)
```bash
sudo iptables -L -n -v
```

Если видите список правил - используется iptables.

## Шаг 3: Разрешите исходящие соединения на SMTP порты

### Если используется UFW:

**Проверьте текущие правила:**
```bash
sudo ufw status verbose
```

**Разрешите исходящие соединения на порты 465 и 587:**
```bash
# Разрешаем исходящие соединения на порт 465 (SSL)
sudo ufw allow out 465/tcp

# Разрешаем исходящие соединения на порт 587 (STARTTLS)
sudo ufw allow out 587/tcp
```

**Проверьте, что правила добавились:**
```bash
sudo ufw status numbered
```

### Если используется firewalld:

**Проверьте текущие зоны:**
```bash
sudo firewall-cmd --list-all
```

**Разрешите исходящие соединения:**
```bash
# Для порта 465
sudo firewall-cmd --add-rich-rule='rule family="ipv4" port port="465" protocol="tcp" direction="outbound" accept' --permanent

# Для порта 587
sudo firewall-cmd --add-rich-rule='rule family="ipv4" port port="587" protocol="tcp" direction="outbound" accept' --permanent

# Применить изменения
sudo firewall-cmd --reload
```

**Проверьте правила:**
```bash
sudo firewall-cmd --list-rich-rules
```

### Если используется iptables:

**Добавьте правила для исходящих соединений:**
```bash
# Разрешаем исходящие соединения на порт 465
sudo iptables -A OUTPUT -p tcp --dport 465 -j ACCEPT

# Разрешаем исходящие соединения на порт 587
sudo iptables -A OUTPUT -p tcp --dport 587 -j ACCEPT

# Сохраните правила (для Ubuntu/Debian)
sudo iptables-save | sudo tee /etc/iptables/rules.v4

# Или для CentOS/RHEL
sudo service iptables save
```

**Проверьте правила:**
```bash
sudo iptables -L OUTPUT -n -v
```

## Шаг 4: Проверьте, что порты доступны

**Проверьте доступность порта 465:**
```bash
timeout 5 bash -c "</dev/tcp/smtp.mail.ru/465" && echo "Порт 465 доступен" || echo "Порт 465 недоступен"
```

**Проверьте доступность порта 587:**
```bash
timeout 5 bash -c "</dev/tcp/smtp.mail.ru/587" && echo "Порт 587 доступен" || echo "Порт 587 недоступен"
```

## Шаг 5: Если файрвол не установлен или отключен

Если файрвол не установлен или отключен, проблема может быть в:
1. **Провайдере VPS** - он может блокировать порты на уровне сети
2. **Настройках безопасности VPS** - проверьте панель управления вашего VPS провайдера

## Шаг 6: Проверьте логи файрвола (если нужно)

### Для UFW:
```bash
sudo tail -f /var/log/ufw.log
```

### Для firewalld:
```bash
sudo journalctl -u firewalld -f
```

### Для iptables:
```bash
sudo dmesg | grep -i firewall
```

## Важные замечания

1. **Исходящие соединения обычно разрешены по умолчанию** - файрвол чаще блокирует входящие соединения
2. **Если файрвол не блокирует** - проблема может быть у провайдера VPS
3. **После изменения правил** перезапустите ваш Node.js сервер:
   ```bash
   pm2 restart all
   # или
   npm start
   ```

## Быстрая проверка (все в одной команде)

Выполните эту команду для быстрой диагностики:
```bash
echo "=== Проверка файрволов ===" && \
(sudo ufw status 2>/dev/null && echo "✅ UFW активен") || \
(sudo systemctl is-active firewalld 2>/dev/null && echo "✅ firewalld активен") || \
(sudo iptables -L -n 2>/dev/null | head -5 && echo "✅ iptables активен") || \
echo "⚠️ Файрвол не найден или отключен"
```
