iRZ ATM42.B + Меркурий 230/234/236

Автоматизированная система коммерческого учёта электроэнергии

Модем iRZ ATM42.B опрашивает счётчики Меркурий по шине RS-485 и передаёт данные на сервер платформы. Личный кабинет отображает показания, качество сети, тарифный расход и позволяет управлять нагрузкой дистанционно.

Архитектура

Один модем на шине обслуживает все счётчики объекта

  1. Счётчики Меркурий подключены к общей линии RS-485 (сетевые адреса 0–239), опрос ведётся по протоколу Меркурий (CRC16-MODBUS).
  2. Модем iRZ ATM42.B инкапсулирует команды протокола и передаёт их на сервер через сотовую сеть — статический IP или проводной интернет на объекте не требуются.
  3. Сервер обращается к модему через очередь команд, разделяя доступ к общей шине между счётчиками и исключая коллизии при одновременных запросах.
  4. Личный кабинет получает данные из базы сервера по HTTPS — доступен с любого устройства без установки приложений.

Модем и связь

Контроль канала связи, а не только показаний

Помимо счётчиков платформа отслеживает состояние самого канала связи: уровень сигнала сотовой сети, температуру модуля модема и параметры базовой станции. Потеря связи с объектом фиксируется в кабинете раньше, чем о ней сообщит арендатор или диспетчер.

  • Привязка модема по IMEI (с проверкой контрольной суммы) — подключение занимает не более минуты после SMS-команды
  • Уровень сигнала, оператор, диапазон и идентификатор соты — опрос раз в 60 секунд, история за 2 суток
  • Температура модуля модема — текущее значение и график
  • USSD-запросы к SIM-карте — из личного кабинета, без извлечения карты
Приборы учёта

Несколько счётчиков на одной линии RS-485

Несколько приборов учёта на общей шине опрашиваются через единую очередь команд — это исключает коллизии при одновременных запросах к разным адресам. Каждый счётчик числится в кабинете отдельно, с собственным расположением, серийным номером и историей показаний.

  • Поиск счётчиков на шине — автоматическое сканирование адресов 0–239
  • Серийный номер и дата выпуска считываются с прибора автоматически
  • Расположение и модель указываются вручную и хранятся при приборе
  • Переключение между приборами — без перезагрузки страницы
Показания

Параметры сети по каждой фазе

Личный кабинет отображает не только энергопотребление, но и параметры качества сети: напряжение, ток, мощность и коэффициент мощности по каждой фазе. Тревожные события счётчика, например вскрытие корпуса, выводятся отдельным уведомлением.

  • Напряжение, ток, активная/реактивная/полная мощность и cos φ — по фазам A, B, C
  • Частота сети и температура счётчика
  • Тревожные события счётчика — уведомление в кабинете, подтверждение вручную
  • Журнал событий — история тревог по запросу, глубина до 40 записей
АСКУЭ

Почасовые показания с автоматическим восполнением истории

При первой синхронизации платформа выгружает всю доступную историю профиля из памяти счётчика. Для моделей, не поддерживающих профиль почасовки на уровне протокола, показания восстанавливаются расчётным способом — по накопленной энергии между опросами.

  • Почасовой расход — календарной сеткой, за любой месяц из 24-месячной истории
  • Автоматическая догрузка истории при первом подключении счётчика
  • Расчётное восполнение почасовки для моделей без профиля (например, Меркурий 230)
  • Накопленная энергия по тарифам, по направлениям потребления и отдачи
Оплаты

Расчёт стоимости с учётом смены тарифа

Тариф задаётся на объект (модем), с историей ставок по дате действия. При смене тарифа в течение расчётного периода стоимость считается раздельно по дням действия каждой ставки — расхождения на границе периода не возникает.

  • Тариф ₽/кВт·ч — с историей ставок по дате действия
  • Показания на начало и конец периода — расчётным способом, без ручного снятия
  • Отчёт по всем счётчикам объекта — выгрузка в XLSX или CSV за произвольный период
  • Коэффициент трансформации — для объектов с трансформаторами тока
Регистратор

История мгновенных величин, а не только энергии

Помимо учёта энергии платформа ведёт собственный журнал мгновенных величин с дискретностью 10 минут — напряжения, тока, мощности, частоты и температуры. Это позволяет впоследствии восстановить картину происшествия на объекте, а не полагаться только на показания энергии.

  • Дискретность записи — 10 минут, глубина хранения — 24 месяца
  • Просмотр за сутки, неделю, месяц, год или весь период
  • Масштабирование графика с точным считыванием значения по ползунку
  • Автоматическое укрупнение точек на больших периодах — без потери отклика интерфейса
Входы / выходы

Дистанционное управление с подтверждением состояния

Команда на включение нагрузки и факт её включения — не одно и то же. Платформа сверяет команду с состоянием вспомогательного контакта пускателя и явно показывает результат: подтверждено, отклонено или контакт не откликнулся.

  • Включение и отключение нагрузки — через выход GPO модема
  • Обратная связь по вспомогательному контакту пускателя, настраиваемому под объект
  • Направление и уровень входов/выходов GPIO1–3 — настраиваются под задачу
  • Изменение конфигурации — SMS-командой, текст которой формируется в кабинете
Управление объектами

Один сервис — множество независимых объектов

Каждый объект — отдельный личный кабинет с собственным логином, данные и приборы разных объектов не пересекаются. Администратор видит сводку по всем объектам и может войти в кабинет любого из них для диагностики без запроса пароля.

  • Отдельный кабинет и логин на каждый объект
  • Сводная панель администратора — число счётчиков, модемов, объём данных по каждому объекту
  • Диагностический вход в кабинет объекта без смены пароля клиента
  • Подключение нового объекта — по IMEI модема, без обращения к разработчику
Особенности реализации

Технические решения, определяющие устойчивость системы

Восполнение истории
Если счётчик не отдаёт профиль почасовки (протокольное ограничение части моделей), платформа восстанавливает почасовые значения из накопленной энергии — без пропусков в графике.
Полная выгрузка при подключении
При первой синхронизации счётчика загружается вся история, доступная в его памяти, а не только новые показания.
Очередь команд на шине
Одновременные запросы к разным счётчикам на одной линии RS-485 обрабатываются последовательно, что исключает коллизии и искажение ответов.
Единая формула расчёта
Стоимость в разделе «Оплаты» и в выгруженном отчёте вычисляется одной и той же функцией — расхождений между кабинетом и отчётностью не возникает.
Подтверждение по обратной связи
Включение нагрузки проверяется по состоянию вспомогательного контакта пускателя, а не только по факту отправки команды.
