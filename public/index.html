Настройки модема

📱 Как настройки доходят до модема:

  1. Вы заполняете форму и нажимаете "Применить настройки"
  2. Система формирует SMS-команды в формате IRZ (например: 5492 1AT$CLNT_IPP1=147.45.212.205,2001)
  3. Если SMS-шлюз настроен: Команды автоматически отправляются на номер модема
  4. Если SMS-шлюз НЕ настроен: Команды показываются в консоли сервера - отправьте их вручную с телефона
  5. Модем получает SMS, обрабатывает команду и применяет настройки

💡 Все настройки сохраняются в файл и не пропадут после перезагрузки!

Режим работы

Режим "Клиент": Модем подключается к вашему серверу по указанному IP и порту.

⚠️ Проблема с AT-командами в режиме "Клиент": Даже с протоколом iRZ Collector модем может не отвечать на AT-команды, так как протокол требует специального формата пакетов. Наш сервер не реализует полный протокол iRZ Collector.

✅ Режим "Сервер" (рекомендуется для мониторинга): Модем ждёт подключений на указанном порту. В этом режиме можно отправлять AT-команды напрямую через TCP без протокола. Для работы нужно знать IP-адрес модема (он будет определен автоматически из последнего подключения).

💡 Альтернатива: Используйте SMS-команды для получения данных (см. вкладку "Мониторинг" → кнопка "📱 Команды для SMS").

Мониторинг модема

Выбор модема

💡 Важно для получения данных:

  • Режим "Сервер": Модем ждёт подключений. AT-команды работают напрямую через TCP. Рекомендуется для мониторинга!
  • Режим "Клиент": Модем подключается к серверу. AT-команды работают только через протокол iRZ Collector (нужен специальный сервер).
  • Для получения данных модем должен быть подключен (статус "Онлайн")
  • Если модем отвечает "ACCESS ERROR", нужно сначала отправить пароль сервисного режима через SMS: 5492 1AT$ATM_PWD=5492

Настройки отправки SMS

📝 Примечание: Если SMS-шлюз не настроен, команды будут выводиться в консоль сервера (режим тестирования).

🔧 Варианты настройки SMS:

  • Через API SMS-шлюза: Укажите URL и API ключ вашего SMS-провайдера
  • Через GSM-модем: Подключите GSM-модем к серверу и укажите COM-порт
  • Режим тестирования: Оставьте выключенным - команды будут показаны в логах сервера
