# Управление модемом IRZ AMT 42.B

Веб-интерфейс для управления модемом IRZ AMT 42.B через SMS-команды.

## Возможности

- Управление входами и выходами (GPIO) модема
- Настройка режима работы (Клиент/Сервер)
- Настройка интерфейсов RS485/RS232
- Управление ждущим режимом
- Конфигурация SMS-шлюза для отправки команд

## Установка

1. Установите зависимости:
```bash
npm install
```

2. Запустите сервер:
```bash
npm start
```

3. Откройте браузер и перейдите по адресу:
```
http://147.45.212.205:3004
```

## Настройка SMS-шлюза

Для работы с реальными модемами необходимо настроить SMS-шлюз:

1. Перейдите в раздел "Конфигурация"
2. Укажите URL API вашего SMS-шлюза
3. Введите API ключ
4. Включите отправку SMS

**Примечание:** Если SMS-шлюз не настроен, команды будут выводиться в консоль сервера (режим тестирования).

## Использование

### Добавление модема

1. Перейдите в раздел "Модемы"
2. Введите номер телефона модема
3. Укажите название и пароль (по умолчанию 5492)
4. Нажмите "Добавить модем"

### Управление GPIO

1. Перейдите в раздел "Входы/Выходы"
2. Выберите модем из списка
3. Используйте кнопки для управления выходами:
   - **Включить (1)** - установить высокий уровень
   - **Выключить (0)** - установить низкий уровень
   - **Импульс** - отправить импульс

### Настройка режима работы

1. Перейдите в раздел "Настройки"
2. Выберите модем
3. Настройте режим работы:
   - **Клиент** - подключение к серверу
   - **Сервер** - ожидание входящих подключений

## Формат SMS-команд

Система автоматически формирует SMS-команды в формате, требуемом модемом IRZ:

- Управление GPIO: `<пароль> gpio<X> set=<0/1>`
- Импульс: `<пароль> gpio<X> impulse=<0/1>`
- Настройка режима: `<пароль> <0/1>AT$<команда>=<параметры>`
