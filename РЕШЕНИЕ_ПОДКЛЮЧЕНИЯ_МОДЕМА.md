# Решение проблемы подключения модема

## Проблема

Модем принял SMS-команды и пытается подключиться к серверу, но статус показывает "Офлайн", и в логах видно:
```
Сокет 0 (147.45.212.205:2001) подключение закрыто
```

## Причина

**На сервере не было TCP-сервера**, который принимает подключения от модемов на порту 2001.

Модем настроен правильно и пытается подключиться, но сервер не слушает этот порт, поэтому соединение сразу закрывается.

## Решение

Я добавил **TCP-сервер** в код, который:
- ✅ Слушает порт 2001
- ✅ Принимает подключения от модемов
- ✅ Автоматически обновляет статус модема на "Онлайн" при подключении
- ✅ Отслеживает активные подключения

## Что нужно сделать

### 1. Перезапустите сервер

```bash
pm2 restart irz-modem-control
```

Или если сервер запущен не через PM2:
```bash
# Остановите сервер (Ctrl+C)
# Запустите снова
node server.js
```

### 2. Проверьте логи

После перезапуска вы должны увидеть в логах:
```
📡 TCP-сервер для модемов запущен на порту 2001
   Модемы могут подключаться по адресу: 147.45.212.205:2001
```

### 3. Дождитесь подключения модема

Модем автоматически попытается подключиться (обычно в течение 1-2 минут после применения настроек).

В логах вы увидите:
```
📱 Новое подключение от модема: [IP-адрес]
✅ Модем [название] ([номер]) подключен
```

### 4. Проверьте статус в интерфейсе

- Откройте веб-интерфейс
- Статус модема должен измениться с "Офлайн" на "Онлайн"
- Статус обновляется автоматически каждые 5 секунд

## Как это работает

1. **Модем подключается** к серверу по адресу `147.45.212.205:2001`
2. **TCP-сервер принимает** подключение
3. **Статус модема** автоматически меняется на "Онлайн"
4. **Сервер отслеживает** активное подключение
5. **При отключении** статус меняется обратно на "Офлайн"

## Проверка работы

### Проверка 1: TCP-сервер запущен

```bash
# Проверьте, что порт 2001 слушается
sudo netstat -tlnp | grep 2001
# или
sudo ss -tlnp | grep 2001
```

Должны увидеть что-то вроде:
```
tcp  0  0  0.0.0.0:2001  0.0.0.0:*  LISTEN  [PID процесса]
```

### Проверка 2: Модем подключается

В логах PM2:
```bash
pm2 logs irz-modem-control --lines 50
```

Должны увидеть сообщения о подключении модема.

### Проверка 3: Статус в интерфейсе

В веб-интерфейсе на вкладке "Модемы" статус должен быть "Онлайн" (зеленый).

## Если модем все еще не подключается

1. **Проверьте настройки модема:**
   - IP-адрес: `147.45.212.205`
   - Порт: `2001`
   - Режим: "Клиент"

2. **Проверьте, что модем в сети:**
   - В программе ATM Control SE должен быть виден IP-адрес модема
   - Уровень сигнала должен быть достаточным

3. **Проверьте файрвол:**
   ```bash
   # Убедитесь, что порт 2001 открыт
   sudo ufw allow 2001/tcp
   # или для iptables
   sudo iptables -A INPUT -p tcp --dport 2001 -j ACCEPT
   ```

4. **Проверьте логи модема:**
   - В программе ATM Control SE смотрите логи
   - Должны быть попытки подключения к `147.45.212.205:2001`

## Важно

- Статус "Офлайн" в интерфейсе **не означает**, что модем не работает
- Модем может быть настроен правильно, но просто не подключен к серверу
- После добавления TCP-сервера модем должен подключиться автоматически
