# Инструкция по настройке модема через SMS-команды

## Почему модем показывает "Офлайн"?

Статус "Офлайн" - это нормально! Система пока не проверяет реальное подключение модема. После настройки и подключения модем будет работать, даже если статус останется "Офлайн".

## Пошаговая настройка модема

### Шаг 1: Настройка SMS-шлюза (опционально)

Если у вас есть возможность отправлять SMS через API или GSM-модем:

1. Перейдите на вкладку **"Конфигурация"**
2. Выберите способ отправки SMS:
   - **Через API SMS-шлюза**: Укажите URL и API ключ
   - **Через GSM-модем**: Подключите модем к серверу и укажите COM-порт
3. Включите отправку SMS (поставьте галочку)
4. Нажмите "Сохранить настройки"

**Если SMS-шлюз не настроен** - не страшно! Все команды будут показаны в консоли сервера, и вы сможете отправить их вручную.

### Шаг 2: Настройка режима работы модема

1. Перейдите на вкладку **"Настройки"**
2. Выберите ваш модем из списка
3. Настройте **"Режим работы"**:

   **Режим "Клиент"** (рекомендуется):
   - Модем будет подключаться к вашему серверу
   - Укажите IP-адрес сервера (например: `147.45.212.205`)
   - Укажите порт (например: `2001`)
   - Номер соединения: `1` (по умолчанию)

   **Режим "Сервер"**:
   - Модем будет ждать подключений от клиентов
   - Укажите только порт для прослушивания

4. Нажмите "Применить настройки"

### Шаг 3: Настройка интерфейсов

1. На той же вкладке "Настройки" найдите раздел **"Настройка интерфейсов"**
2. Выберите интерфейс:
   - **RS485** - для подключения к счетчикам (Modbus)
   - **RS232** - для прямого подключения устройств
3. Настройте параметры:
   - **Скорость**: обычно `9600` или `19200` бод
   - **Биты данных**: обычно `8`
   - **Стоп-биты**: обычно `1`
   - **Четность**: обычно `Нет`
4. Нажмите "Применить настройки интерфейса"

### Шаг 4: Проверка команд

После настройки:

1. **Если SMS-шлюз настроен**: Команды автоматически отправятся на модем
2. **Если SMS-шлюз не настроен**: 
   - Откройте консоль сервера (где запущен Node.js)
   - Вы увидите все команды, которые нужно отправить
   - Отправьте их вручную на номер модема

## Примеры SMS-команд

После настройки через веб-интерфейс, система сформирует команды в формате:

```
5492 1AT$CLNT_SET1=1,0,0,1
5492 1AT$CLNT_IPP1=147.45.212.205,2001
```

Где:
- `5492` - пароль модема (по умолчанию)
- `1` - применить сразу (0 = сохранить, но не применять)
- `AT$CLNT_SET1` - настройка соединения №1 в режиме Клиент
- `AT$CLNT_IPP1` - IP и порт для соединения №1

## Что делать после настройки?

1. **Подождите несколько секунд** - модем обработает команды
2. **Проверьте подключение** - модем должен подключиться к серверу (если режим Клиент)
3. **Проверьте логи сервера** - там будет видно, подключился ли модем

## Полезные команды

- **Управление GPIO**: Вкладка "Входы/Выходы" - для управления выходами модема
- **Ждущий режим**: Вкладка "Настройки" - для экономии энергии при отсутствии данных

## Нужна помощь?

Если что-то не работает:
1. Проверьте логи сервера - там видны все команды
2. Убедитесь, что номер модема указан правильно
3. Проверьте, что пароль модема правильный (по умолчанию `5492`)
