# 🔧 Настройка уведомлений для GPO4

## 📋 Что такое GPO4?

**GPO4** - это **силовой выход** (General Purpose Output), который отличается от GPIO1-GPIO3:

- **GPIO1-GPIO3** - могут быть настроены как **входы** или **выходы**
- **GPO4** - это **только выход** (не может быть входом)
- **GPO4** - силовой выход с напряжением питания модема или фиксированным 7,5В

---

## ⚠️ Важное отличие от GPIO1-GPIO3

### Для GPIO1-GPIO3 (входы):
- ✅ Можно настроить автоматическую отправку данных через `GPIO_SEND<X>=1`
- ✅ Модем автоматически отправляет данные при изменении состояния
- ✅ Работает только для GPIO, настроенных как **входы**

### Для GPO4 (выход):
- ❌ Команда `GPIO_SEND4` **НЕ РАБОТАЕТ** (работает только для входов)
- ⚠️ GPO4 - это выход, он не может быть настроен как вход
- ✅ Но модем может отправлять данные о состоянии GPO4 в формате `^GPIO_OUT4: <значение>`

---

## 🔧 Как получить уведомления о GPO4?

### Вариант 1: Модем автоматически отправляет данные (если поддерживается)

Некоторые модемы могут автоматически отправлять данные о состоянии GPO4 при его изменении. Проверьте логи сервера - если модем отправляет данные в формате:
- `^GPIO_OUT4: 0` или `^GPIO_OUT4: 1`
- `GPIO_OUT4: 0` или `GPIO_OUT4: 1`

То код уже должен их распознавать и отправлять уведомления!

**Проверка:**
1. Измените состояние GPO4 через веб-интерфейс или команду
2. Проверьте логи сервера - должны быть сообщения:
   ```
   📱 Извлечено состояние GPIO4 из данных модема ...: 1 (output)
   📢 Отправлено Telegram уведомление о ФИЗИЧЕСКОМ изменении GPIO4...
   ```

---

### Вариант 2: Запрос состояния GPO4 периодически

Если модем не отправляет данные автоматически, можно периодически запрашивать состояние GPO4:

**Через веб-интерфейс:**
1. Перейдите на вкладку **"Входы/Выходы"**
2. Выберите модем
3. Нажмите кнопку **"Обновить"** для чтения состояния GPIO
4. Система запросит состояние всех GPIO, включая GPO4

**Через API:**
```
GET /api/modems/{phoneNumber}/gpio?gpioNumber=4
```

---

### Вариант 3: Уведомления при команде из веб-интерфейса

Если вы изменяете GPO4 через веб-интерфейс, уведомление отправится автоматически (если включено правило "Команды GPIO из веб-интерфейса").

**Настройка:**
1. Перейдите на вкладку **"Конфигурация"**
2. Установите галочку **"☑ Команды GPIO из веб-интерфейса"**
3. Нажмите **"Сохранить настройки Telegram"**

---

## 📝 Управление GPO4

### Установить состояние GPO4 через SMS:

```
5492 0AT$GPIO_OUT4=0,1,1
5492 1AT$CLNT_SET1=1,0,0,1
```

**Пояснение:**
- `GPIO_OUT4=0,1,1` - триггер (0), сохранение состояния включено (1), состояние при срабатывании = 1
- Первый параметр: `0` = триггер, `1` = импульс
- Второй параметр: `0` = не сохранять состояние, `1` = сохранять
- Третий параметр: `0` = физический 0, `1` = физическая 1

### Установить напряжение GPO4:

```
5492 0AT$GPIO_VCC4=0
5492 1AT$CLNT_SET1=1,0,0,1
```

**Пояснение:**
- `GPIO_VCC4=0` - напряжение питания модема
- `GPIO_VCC4=1` - фиксированное напряжение 7,5В

## 🔍 Диагностика

### Проверка 1: Модем отправляет данные о GPO4?

**Проверьте логи сервера** - должны быть сообщения:
```
📨 Данные от модема ...: ^GPIO_OUT4: 1
📱 Извлечено состояние GPIO4 из данных модема ...: 1 (output)
```

**Если данных нет:**
- GPO4 - это выход, модем может не отправлять данные автоматически
- Попробуйте изменить состояние GPO4 и проверьте логи

---

### Проверка 2: Код распознает формат?

**Проверьте логи сервера** - если формат не распознан:
```
⚠️  Обнаружено упоминание GPIO в данных, но формат не распознан:
   📨 Данные: ...
```

**Если формат не распознается:**
- Проверьте, какой формат данных отправляет модем
- Возможно, нужно добавить поддержку нового формата в код

---

### Проверка 3: Уведомления включены?

**Проверьте настройки:**
1. Перейдите на вкладку **"Конфигурация"**
2. Убедитесь, что установлена галочка **"☑ Физическое изменение GPIO"**
3. Нажмите **"Сохранить настройки Telegram"**

**Проверьте логи сервера:**
```
💡 Уведомления включены: ДА
📢 Отправлено Telegram уведомление о ФИЗИЧЕСКОМ изменении GPIO4...
```

---

## ⚠️ Ограничения

1. **GPO4 - только выход:**
   - GPO4 не может быть настроен как вход
   - Команда `GPIO_SEND4` не работает (работает только для входов)

2. **Автоматическая отправка данных:**
   - Модем может не отправлять данные о GPO4 автоматически
   - Зависит от версии прошивки и настроек модема

3. **Формат данных:**
   - Модем может отправлять данные в разных форматах
   - Если формат не распознается, проверьте логи

## 📋 Резюме

### Для получения уведомлений о GPO4:

1. ✅ **Включите уведомления** в веб-интерфейсе:
   - "☑ Физическое изменение GPIO" - для автоматических уведомлений (если модем отправляет данные)
   - "☑ Команды GPIO из веб-интерфейса" - для уведомлений при командах из веб-интерфейса

2. ✅ **Проверьте логи сервера** - должны быть сообщения о получении данных о GPO4

3. ✅ **Если модем не отправляет данные автоматически:**
   - Используйте уведомления при командах из веб-интерфейса
   - Или запрашивайте состояние GPO4 периодически через API
