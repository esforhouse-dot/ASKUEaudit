# Объяснение статуса PM2 и нагрузки сервера

## Что означает `U: 0` в PM2?

В PM2 колонка `U` может показывать:
- **Uptime** (время работы) в секундах - если процесс только что запустился, будет `0`
- **Количество перезапусков** - зависит от версии PM2

**Важно:** `U: 0` не обязательно означает проблему! Это может означать:
- ✅ Процесс только что запустился (нормально)
- ⚠️ Процесс часто перезапускается (проблема)

## Как проверить, есть ли проблема?

### 1. Проверьте детальную информацию:

```bash
pm2 describe irz-modem-control
```

Обратите внимание на:
- **restart_time** - количество перезапусков
- **pm_uptime** - время работы процесса
- **status** - должен быть "online"

### 2. Проверьте логи на ошибки:

```bash
pm2 logs irz-modem-control --lines 50 --err
```

Если видите постоянные ошибки - это проблема.

### 3. Используйте скрипт проверки:

```bash
chmod +x check-health.sh
./check-health.sh
```

## Нормальные показатели:

✅ **Хорошо:**
- Статус: `online`
- Перезапусков: 0-5 (после первоначального запуска)
- CPU: 0-5%
- Память: 20-100 MB
- Сервер отвечает на HTTP запросы

⚠️ **Проблема:**
- Статус: `errored` или `stopped`
- Перезапусков: постоянно растет
- В логах видны ошибки
- Сервер не отвечает

## Нагрузка на сервер

### Проверка общей нагрузки:

```bash
# Загрузка CPU
uptime

# Использование памяти
free -h

# Использование диска
df -h

# Топ процессов по CPU
top -bn1 | head -20
```

### Наш процесс обычно использует:

- **CPU:** 0-1% (почти ничего)
- **Память:** 20-50 MB (очень мало)
- **Диск:** минимально (только логи)

**Вывод:** Даже если процесс перезапускается, он НЕ нагружает сервер сильно!

## Что делать, если процесс перезапускается?

1. **Проверьте логи:**
```bash
pm2 logs irz-modem-control --lines 100
```

2. **Если видите ошибки** - исправьте их

3. **Если ошибок нет, но перезапуски есть:**
   - Это может быть нормально (PM2 перезапускает при сбоях)
   - Проверьте, что сервер отвечает: `curl http://localhost:3004`

4. **Если сервер работает** - не переживайте! Перезапуски PM2 - это защита от сбоев.

## Вывод

**Если сервер отвечает и работает** - все в порядке! 
`U: 0` может быть нормальным, если процесс только запустился.

**Проверьте реальную работу:**
```bash
curl http://localhost:3004
```

Если видите HTML страницу - сервер работает! 🎉
