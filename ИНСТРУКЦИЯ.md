# Инструкция по использованию веб-интерфейса управления модемом IRZ AMT 42.B

## Быстрый старт

### 1. Установка и запуск

На VPS сервере выполните:

```bash
# Установите зависимости
npm install

# Запустите сервер
npm start
```

Сервер будет доступен по адресу: **http://147.45.212.205:3004**

### 2. Первый запуск

1. Откройте браузер и перейдите на `http://147.45.212.205:3004`
2. Вы увидите интерфейс с несколькими разделами:
   - **Модемы** - управление списком модемов
   - **Входы/Выходы** - управление GPIO
   - **Настройки** - настройка режима работы модема
   - **Конфигурация** - настройка SMS-шлюза

## Работа с модемами

### Добавление модема

1. Перейдите в раздел **"Модемы"**
2. Заполните форму:
   - **Номер телефона модема** - номер SIM-карты в модеме (например: +79001234567)
   - **Название** - любое удобное название
   - **Пароль** - пароль для SMS-команд (по умолчанию: 5492)
3. Нажмите **"Добавить модем"**

### Управление входами и выходами (GPIO)

1. Перейдите в раздел **"Входы/Выходы"**
2. Выберите модем из списка
3. Используйте кнопки для управления:
   - **Включить (1)** - установить высокий уровень на выходе
   - **Выключить (0)** - установить низкий уровень на выходе
   - **Импульс** - отправить импульс на выход

**Доступные выходы:**
- GPIO 1, 2, 3 - программируемые входы/выходы
- GPO 4 - силовой выход
- GPO 5-8 - выходы на разъёме DB9-F (DCD, DSR, CTS, RING)

## Настройка режима работы модема

### Режим "Клиент"

Модем подключается к серверу сбора данных:

1. Перейдите в раздел **"Настройки"**
2. Выберите модем
3. Выберите режим **"Клиент"**
4. Укажите:
   - **IP-адрес сервера** (например: 192.168.1.100)
   - **Порт сервера** (например: 5009)
   - **Номер соединения** (1-5)
5. Нажмите **"Применить настройки"**

### Режим "Сервер"

Модем ожидает входящие подключения:

1. Выберите режим **"Сервер"**
2. Укажите **порт** для входящих подключений (например: 5009)
3. Нажмите **"Применить настройки"**

## Настройка интерфейсов

Модем поддерживает два интерфейса: RS485 и RS232.

1. В разделе **"Настройки"** выберите модем
2. В разделе **"Настройка интерфейсов"** укажите:
   - **Интерфейс** - RS485 или RS232
   - **Скорость** - скорость передачи данных (9600, 19200, и т.д.)
   - **Биты данных** - 7 или 8
   - **Стоп-биты** - 1, 1.5 или 2
   - **Четность** - Нет, Четная или Нечетная
3. Нажмите **"Применить настройки интерфейса"**

## Ждущий режим

Ждущий режим позволяет экономить трафик и электроэнергию:

1. В разделе **"Настройки"** выберите модем
2. В разделе **"Ждущий режим"**:
   - **Включить ждущий режим** - модем перестанет поддерживать GPRS-соединение
   - **Выключить ждущий режим** - модем восстановит GPRS-соединение
3. Можно указать номер соединения (0 = все соединения Сервер, 1-5 = конкретное соединение Клиент)

## Настройка SMS-шлюза

Для работы с реальными модемами необходимо настроить отправку SMS-команд:

1. Перейдите в раздел **"Конфигурация"**
2. Настройте параметры:
   - **Включить отправку SMS** - активировать отправку команд
   - **URL API SMS-шлюза** - адрес API вашего SMS-провайдера
   - **API ключ** - ключ для доступа к API
   - **Использовать GSM-модем** - альтернативный способ отправки SMS
   - **Порт GSM-модема** - COM-порт модема (например: COM3)

**Важно:** Если SMS-шлюз не настроен, команды будут выводиться в консоль сервера (режим тестирования). Это позволяет проверить работу интерфейса без реальной отправки SMS.

## Формат SMS-команд

Система автоматически формирует команды в формате, требуемом модемом IRZ:

- **Управление GPIO:** `5492 gpio1 set=1` (включить GPIO1)
- **Импульс:** `5492 gpio1 impulse=0` (отправить импульс на GPIO1)
- **Настройка режима:** `5492 1AT$SRV_PORT=5009` (настроить порт сервера)

## Устранение неполадок

### Команды не отправляются

1. Проверьте, что SMS-шлюз настроен в разделе "Конфигурация"
2. Проверьте логи сервера для отладки
3. Убедитесь, что номер телефона модема указан правильно

### Модем не отвечает

1. Проверьте, что модем включен и зарегистрирован в сети
2. Убедитесь, что пароль для SMS-команд указан правильно (по умолчанию: 5492)
3. Проверьте уровень сигнала модема

### Интерфейс не открывается

1. Убедитесь, что сервер запущен: `npm start`
2. Проверьте, что порт 3003 открыт в файрволе
3. Проверьте логи сервера на наличие ошибок
